# 发布准备与获授权发布

阅读 [任务协议](references/task-protocol.md)。

确认目标版本、目标提交、发布组件和现有发布规则。核对上次发布到目标提交的真实差异，分类为功能、修复、兼容性、依赖和文档；自动摘要须核对原始 PR。
分别记录测试证据、兼容范围、生成产物来源、签名或溯源要求和发布凭据的权限需求。不能从工作流文件推断凭据已经可用。
无发布记录时明确标记首次发布，不虚构前一版本。无法确定版本或发布范围时澄清，不自行推送标签。
生成变更日志草稿、迁移说明、发布步骤、恢复或撤回方案和未满足条件列表。
固定检查版本徽章、安装示例、截图、演示和项目时间线是否受影响；真实发布前将所有内容标为草稿，不提前展示成功。
默认结果是发布准备 PR 或草稿材料；该 PR 的自动合并不等于执行发布。检查失败时诊断、修复并重验。
用户已明确要求发布指定版本时，按任务协议单独记录授权与制品范围，在维护 PR 合并后从合并提交构建、核对摘要，创建固定标签和 Release 草稿，上传并验证制品后公开，最后下载核验。版本已存在时先读取状态，不覆盖发行或移动标签；未经发布授权不执行这些写操作。

选择实现或评审标准时，按需阅读 [研究案例](references/cases.md)，区分来源事实与本插件建议。
