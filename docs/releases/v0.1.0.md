# Better Codex Info v0.1.0

首次发布。Better Codex Info 在 Codex 输入框底部提供轻量统计胶囊，并可原地展开为本机会话分析中心。

## Highlights

- 实时展示轮次、步骤、TPS、累计 Token、缓存命中率和上下文占用。
- 会话统计、Token 构成与上下文构成详情。
- Token、缓存、速度和工具耗时趋势切换。
- 按时间、项目、模型、推理强度和主/子代理筛选历史。
- 逐轮 TTFT、TPS、Token、工具耗时和异常状态。
- Token 预算、上下文阈值、缓存命中率提醒。
- CSV/JSON 导出和本地隐私边界。

## Installation

Windows x64 用户下载 `Better Codex Info Setup 0.1.0.exe`。安装后启动应用，并将 Codex 保持在前台；悬浮层会自动停靠在 Codex 底部。

macOS x64/arm64 产物由 `.github/workflows/ci.yml` 在 macOS runner 构建。当前没有 Developer ID 签名和公证。

Release 同时提供 `SHA256SUMS.txt`。发布工作流会在上传后重新下载全部制品并校验摘要，确认一致后再公开 Release。

## Verification

- TypeScript typecheck
- 9 unit tests
- Electron source and packaged application E2E flows
- GitHub Actions 在 Windows 与 macOS 上完成生产构建和打包
- Release 下载回验全部制品及 SHA-256

## Known limitations

- Codex 未持久化“仅浏览会话”的选择状态，胶囊跟随最近产生事件的主会话；可在历史中固定会话。
- 上下文分类为归一化估算。
- 云端或已删除且没有本地日志的会话无法分析。
