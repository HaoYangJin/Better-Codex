# 仓库维护审查

阅读 [任务协议](references/task-protocol.md)。审查默认只读；发现问题不自动修改。

按仓库类型检查文档与入口、贡献和责任归属、测试和 CI、生成代码、依赖管理、版本和发布、安全响应、AI 指令，以及固定的展示与玩法维度。
每项输出当前证据、影响、适用性、建议和来源位置。公开资料没有显示的规则写为“未知”或“所查范围未见”，不能声称不存在。
区别文件存在、配置内容、工作流实际运行和平台生效设置。Star、下载量和体量不作为维护质量分数。
按阻碍本次交付、持续维护风险、可选体验改进排序。对个人小仓库给出轻量方案，不套用大型组织的全部流程。
展示部分检查私有信息外传、无效链接、徽章真实性、图片主题、演示可用性及更新成本。审查报告不计入已完成的修复。

选择实现或评审标准时，按需阅读 [研究案例](references/cases.md)，区分来源事实与本插件建议。
