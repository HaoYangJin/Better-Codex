# 技能目录

[中文首页](../README.md) · [English](../README.en.md)

| 名称 | 用途 | 前提与替换要求 |
| --- | --- | --- |
| [项目创建与接入](repo-intake/SKILL.md) | 为当前项目启用 Big-Repo，建立维护配置与展示入口。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [维护与自动交付](maintenance-delivery/SKILL.md) | 完成本轮需求与相关说明，验证、独立审查后按策略交付。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [仓库流程审查](repo-audit/SKILL.md) | 只读审查当前仓库的协作、验证、发布和展示流程。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [版本准备与发布](release-preparation/SKILL.md) | 为当前项目准备下一版本，只有明确版本授权才执行发布。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [技能维护](skill-maintenance/SKILL.md) | 审查并改进当前技能，检查触发、资源和验证。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [仓库展示与玩法](repo-showcase/SKILL.md) | 补齐当前仓库的功能导航、可视化和交互体验。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [Git 提交整理](git-commit/SKILL.md) | 检查本轮改动并按项目约定组织精确提交。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |
| [技能编写](skill-authoring/SKILL.md) | 为这类重复任务编写可独立复制的技能。 | AI 客户端；涉及交付另需 Python 3.11+、Git 和已认证 gh |

模板必须替换全部提示项；技能应复制整个目录。工作流与离线探索台需要完整插件。
