# 仓库展示与玩法

阅读 [任务协议](references/task-protocol.md) 和 [六类玩法目录](references/showcase-catalog.md)。

支持推荐、生成、审查、更新四种模式。先确认公开性、受众、技术栈、真实数据、现有内容和授权；公开性未知按私有处理。
始终检查增长活动、状态徽章、项目门面、快速体验、社区参与、项目故事六类，但只推荐适用项目，不要求全部加入。

生成前给出候选 Markdown 或补丁预览，标出外部请求、成本和后续维护方式；再按已有授权修改，不反复要求已获授权的普通操作确认。
私有仓库使用本地素材、静态展示和仓库内链接，不把仓库标识发给公开服务；不创建带令牌的 URL。
没有历史数据就不声称增长，没有发布就不生成发布成功故事；用户明确要求时，公开仓库可加入 Star History 图及文字回退。
截图、GIF、终端演示先检查敏感信息、路径、许可与体积；明暗主题分别验证。在线体验仅链接已验证入口，创建或部署新服务另需明确任务授权。
徽章必须对应真实仓库、分支、工作流、包名与许可证；未知数据写为未知。贡献者和致谢来自真实记录，不能虚构。
使用有边界标记的托管区避免重复插入；只更新该区并保留用户其他内容。外部服务不可用时保留文字或本地替代，不自动开启定时更新任务。
交付 diff、检查结果、第三方依赖、未验证远程入口和移除方法。验证失败时按协议诊断、修复和重验，外部阻塞才交接。

选择实现或评审标准时，按需阅读 [研究案例](references/cases.md)，区分来源事实与本插件建议。

## 2.0.0 离线探索台

完整插件提供 scripts/explore.py 与 assets/explorer.html：`--demo --output 新文件.html` 生成固定演示，`--repo 仓库根目录 --output 新文件.html` 生成只读 Git 结构快照。命令在完整插件根目录执行；仅复制本技能目录时不包含该工具，不假设脚本存在。

页面提供能力地图、模板工作台、四种交付演练及三项轻量挑战、版本时间线、六类玩法筛选和 Markdown 快照导出，零网络请求、无需服务器。结构存在不是验证通过，模拟交付不是实际合并。生成前核对输出路径，默认放在目标仓库外；已存在文件不覆盖。分享报告前检查仓库名、分支名和提交标识。生成后验证真实与演示标识、交互阻塞、移动端布局和打包资源完整性。
